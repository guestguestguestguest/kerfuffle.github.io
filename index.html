Kerfuffle Go

Play and observe games on the KGS go server with this native MacOS client -- no java required.

Guide

Getting started

The launcher offers Play on KGS, Edit SGF File, Create SGF File, Settings, Help and Quit

Logging In

Choose Play on KGS and log in with your KGS account. No account yet? Click Register new account to request one from the KGS website. Guest logins are not supported.

Rooms and chat

Each room you have joined appears as a tab. Rooms -> Room List or + lists every room by category; double-click one to join. Rooms you have joined persist after you log out.

Playing games

Rooms -> New Game creates a game offer in the current room. Choose your settings (ranked vs free, color, rules, time etc). To play someone else's offer double-click a challenge in the room's game list and select Offer to Play. The game will open in a separate window. Or use Automatch and let the server pair you.

Settings

Set your default name, rooms to join after login, chat font sizes, board appearance and coordinates, move numbers, time warnings, sounds and server address (you shouldn't have to change this but just in case it moves in the future).

SGF editor

Create or edit standard SGF files. Useful for reviewing games and/or creating custom problems. Variations are marked by letters. Shift-click a stone or intersection (long-press on iPad) to jump to the move played there.

Misc

This app uses the KGS JSON protocol to communicate with the server. View current server stats with a click! KGS AI is not supported. Guest logins are not supported.

Privacy

Kerfuffle Go collects no data of any kind. No personal information, device information, usage data or location. It uses no third-party services — no analytics, advertising or payment processors — and does not access your camera, photos, microphone, contacts or location.
